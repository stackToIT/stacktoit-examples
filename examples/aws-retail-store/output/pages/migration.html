Technical sequencing

The waves, from the dependencies between the units (migration/technical-sequencing.md): a technical order, not a schedule

The run wrote migration/technical-sequencing.md.

It holds the waves computed from the dependencies between the units: a unit comes after every unit it depends on, and the units of one wave do not depend on each other.
