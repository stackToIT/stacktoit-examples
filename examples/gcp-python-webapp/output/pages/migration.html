How far each STACKIT API step has come

2 STACKIT API steps, each with its state and what the state means

A STACKIT API step is a script a person runs; its state says what StackToIT has done with it and never more. StackToIT has run none of them. Only “verified live” rests on a call to the live STACKIT API; any other state means the operator checks the endpoint, the project and the read before the write, as the header of the script lists, before running it. The state changes nothing about how a step is carried out: an alpha or beta API still waits for its opt-in decision, and the checks a script makes itself (the read before the write, the confirmation) are the same.
